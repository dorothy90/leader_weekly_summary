로컬 개발용 화면입니다. 메일·일정은 입력한 사용자 ID의 권한으로 조회합니다.

질문을 입력하면 답변과 근거 자료가 여기에 표시됩니다.
Enter로 전송 · Shift+Enter로 줄바꿈
빠르게는 조회·요약과 병렬 검색과 시간 예산 내 최대 3회 보완 검색으로 문제를 조사하고, 후속 질문에서 앞선 근거를 이어갑니다. 자세히는 비교·경위 질문에 적합합니다. 자세히는 최대3개 항목 검색과 근거 점검으로 시간이 더 걸릴 수 있습니다. 질문은 설정된 LLM 서비스와 실제 검색 인덱스를 사용합니다. 답변이 완성되면 한 번에 표시됩니다. 새 대화는 화면과 대화 연결을 초기화하며 서버 기록을 삭제하지 않습니다.
