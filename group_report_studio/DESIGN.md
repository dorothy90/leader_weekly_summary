# 그룹 주보 UI

참고: [awesome-design-md Vercel 분석](https://github.com/voltagent/awesome-design-md/blob/main/design-md/vercel/DESIGN.md), [shadcn/ui 테마](https://ui.shadcn.com/docs/theming).

문서 편집을 위한 중립적인 작업대. 기존 정적 웹에서 시각 체계를 적용하며 shadcn React 패키지 설치나 기존 레포 설정 변경은 하지 않는다.

- 흰 배경, #18181b 본문·주요 버튼, #71717a 보조 글자, #e4e4e7 경계, #fafafa 사이드바.
- 글자: 시스템 한국어 sans-serif. 본문 13px, 보조 11~12px, 문서 제목 24px. 가중치는 400/500/600.
- 58px 헤더 아래에 216px 탐색 / 유동 문서 / 310px 대화. 긴 내용은 각 영역에서 스크롤.
- 버튼 높이 33px, 모서리 7px, 얇은 선. 굵은 선, 색이 있는 말풍선, 종이 그림자, 홍보형 큰 제목은 사용하지 않는다.
- 첫 화면은 작은 문서 아이콘, 짧은 안내, 작성 버튼. 빈 목차와 빈 버전 영역은 감춘다.
- 설정의 긴 목차 편집은 details로 접는다. 오류·진행·선택·포커스 상태는 시각적으로 구분한다.
- 모바일은 영역을 세로로 배치하고 버튼·설정 입력이 화면 밖으로 나가지 않게 한다.
