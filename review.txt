① 발휘한 실력 — 기술 전문성·문제 해결 역량
- 35개 팀 주간보고 통합 발행 체계 구축·운영: 팀별 주간보고를 수집·가공·요약하여 매주 1개의 통합 보고서로 발행, 분산된 조직별 업무 현황을 한 번에 확인할 수 있는 보고 체계 구현.
- 주간보고 처리 파이프라인 자동화: 메일 수집부터 본문·첨부자료 처리, 검색 데이터 구축, 요약 및 보고서 생성·발송까지 연결하여 반복적인 취합·정리 업무의 자동화 기반 마련.
- 4종 업무정보 통합 RAG 시스템 구축: 임원·팀장의 메일·일정, 주간보고, Wiki 요약을 연결하여 자연어 질문으로 업무 현황과 관련 근거를 검색·요약하는 기능 구현.
- 복합 질문 대응 역량 확보: 키워드·벡터 검색을 결합하고 발신자·기간 조건 및 후속 질문 맥락을 반영하여 인물·시점·주제별 업무정보 조회 기능 구현.
- 빠른 조회·상세 분석 2종 모드 구현: 질문 목적에 따라 검색 방식을 구분하고, 상세 분석에서 최대 3개 검색 과제 병렬 처리와 보완 검색을 지원.
- 품질 검증 기반 마련: 메일 RAG 평가 문항 30개, 다중 대화 평가 사례 16개, 관련 테스트 파일 44개를 구성하여 기능 변경에 따른 검색·대화·예외 처리 검증 기반 확보.
② 발휘한 동기 — 주도성·노력·지속적 개선
- 현업의 반복 업무를 개선 과제로 구체화: 35개 팀의 보고를 개별 확인·취합하는 부담을 줄이기 위해, 주간보고 수집과 통합 보고서 발행 체계를 구축하고 매주 정기 발행 업무에 적용.
- 보고서 발행에서 지식 활용까지 확장: 매주 축적되는 보고자료를 RAG 검색과 연결하여 과거 보고 내용과 관련 업무정보를 후속 질문에 활용할 수 있도록 기능 고도화.
- 실사용 과정의 문제를 지속 개선: 검색 날짜 조건 오류, 발신자 정보 손실, 외부 AI 응답 지연 등을 분석하고 조건 검증·메타데이터 처리·임베딩 요청 방식 개선에 반영.
- 일회성 개발을 넘어 지속 운영 기반 확보: 평가 데이터, 회귀 테스트, API·운영·이관 문서를 마련하여 정기 보고 및 검색 서비스의 유지보수와 후속 확산 기반 구축.

=== y-agent ===

① 발휘한 실력 — 기술 전문성·문제 해결·협업 역량

- **수율 도메인 지식을 AI 분석 체계로 구현:** 현업 인터뷰와 수율 분석 SOP를 바탕으로 숙련 엔지니어의 분석 절차·판단 기준을 구체화하고, **13개 전문 Agent와 24개 Tool**로 구성된 Y-Agent 구축에 기여함. 수율일보·이상감지·Map·불량이력·자재이력·연관분석·Mining을 연결하여 자연어 기반 수율 분석 환경을 구현함.
- **DT 협업을 통한 현업 요구의 기술적 구현:** DT 파견 기간 동안 수율 업무 경험과 DT의 AI 설계·개발 역량을 결합하여, 현업 분석 요구를 Agent 기능과 Workflow로 전환함. 분석 목적에 따라 필요한 Agent와 Tool을 연결하고, 엔지니어가 결과를 확인하며 후속 분석을 선택할 수 있는 Web 기반 협업 환경을 구현함.
- **수율 분석부터 보고까지 4개 대표 활용 시나리오 구현:** **Daily 수율 분석·저수율 자재 분석·고질 불량 분석·Playground**를 구성하여, 수율 현황 확인부터 Good/Bad 선정, Map·이력·Mining 분석, PPT 보고서 생성까지 업무 흐름을 연결함.
- **현업 분석 로직과 통계·머신러닝 결합:** 열화감지에 현업의 판단 기준을 반영하고, Mining에 분류 머신러닝과 Wafer Map 패턴 정보를 결합하여 원인 공정 후보를 탐색하도록 분석 기능을 고도화함. PI 엔지니어가 자연어로 변수 간 관계·비선형성·교호영향 및 목표값 충족 조건을 분석할 수 있는 Playground를 구현함.
- **실제 수율 이슈를 통한 활용성 검증:** 현업 검증 대상 **수율 이슈 7건 중 5건을 검출**하여 실제 업무 적용 가능성을 확인함. 미검출 **2건**은 추가 분석 방법이 필요한 사례로 구분하여 후속 개발 범위를 구체화함.
- **분석 데이터와 결과의 연계 기반 구축:** 주요 원천 데이터를 전처리하여 SYLD DB에 적재하고 Agent 간 분석 데이터를 공유·결합하도록 구성함. 여러 시스템에서 개별적으로 조회·정리하던 정보를 하나의 분석 환경에서 활용할 수 있는 기반을 마련함.

② 발휘한 동기 — 주도성·노력·지속적 개선

- **현업 경험에서 개선 과제를 발굴:** 여러 시스템을 오가며 데이터를 조회하고, 과거 사례와 숙련자의 경험에 의존하던 수율 업무의 불편을 개선 과제로 구체화함. 숙련자의 분석 방법을 조직이 반복적으로 활용할 수 있도록 Y-Agent 개발을 추진함.
- **DT 파견을 공동 개발 성과로 연결:** 파견 기간 동안 현업의 수율 지식과 DT의 AI 기술을 연결하는 역할을 수행함. 현업에서 필요한 분석 방식과 결과 해석 기준을 개발 과정에 반영하며, 업무에 적용할 수 있는 기능으로 구체화함.
- **현업과의 반복 검증 및 개선 추진:** 수율팀과 **Daily 회의**를 진행하며 실제 사용 결과와 분석 타당성을 점검함. 사용자 관점의 **81개 Action Item을 도출**하고, 기능·분석 방법·사용성 개선 과제로 구체화하여 지속적인 고도화에 반영함.
- **검증 과정의 한계를 후속 과제로 전환:** 이슈 7건의 검출 여부와 미검출 원인을 구분하여 현재 분석 범위를 점검하고, 부족한 분석 방법을 추가 개발 대상으로 정리함. 실제 문제 해결 여부를 기준으로 개선 방향을 설정함.
- **현업 활용 범위 확대:** 일부 수율팀 엔지니어의 실제 수율 점검·이슈 분석과 PI 엔지니어의 자유 분석 사례로 활용을 연결함. 사용자 피드백을 수집하며 기술 시연에서 현업 Co-pilot 활용 단계로 발전시키는 데 기여함.
